# Projetos e Desafios

Este repositório reúne os **projetos práticos e desafios de programação** desenvolvidos durante o **Bootcamp Code Girls 2025**, demonstrando a aplicação dos conhecimentos adquiridos de forma prática e estruturada.

## O que você encontrará aqui

- **Desafios básicos de código resolvidos:** problemas de lógica, algoritmos e implementação de funções em Python.
- **Desafios de projeto:** repositório contendo todo conteúdo teório estudado durante o bootcamp.
- **Anotações e insights:** resumos, dicas e observações adquiridas ao longo do aprendizado, que ajudam a fixar os conceitos e servem como referência futura.

## Objetivo

Este repositório tem como objetivo **demonstrar a evolução do aprendizado**, mostrando como transformar teoria em prática. Cada desafio ou projeto foi documentado para ser **fácil de entender e replicar**, servindo como referência ou inspiração para novos projetos.

🌟 **Nota:** Todos os projetos foram desenvolvidos durante o Bootcamp, com foco em **aplicação prática e desenvolvimento de habilidades básicas de programação**.
