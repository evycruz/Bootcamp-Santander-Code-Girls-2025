# AWS CLI e SDKs

O **AWS Command Line Interface (CLI)** e os **AWS SDKs (Software Development Kits)** são ferramentas que permitem **interagir com os serviços da AWS** de forma automatizada e programática.  
Eles são fundamentais para **gerenciar recursos, criar scripts, integrar aplicações** e aumentar a produtividade de desenvolvedores e administradores de sistemas.

---

## AWS CLI (Command Line Interface)

A **AWS CLI** é uma ferramenta de linha de comando que permite **executar comandos da AWS diretamente no terminal**.  
Com ela, é possível **criar, configurar e gerenciar serviços** sem precisar acessar o console web.

### Instalação

```bash
# Em sistemas baseados em Linux/Mac
sudo apt install awscli -y

# Em Windows (PowerShell)
msiexec.exe /i https://awscli.amazonaws.com/AWSCLIV2.msi
